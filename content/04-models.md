这页教你把模型接进来：预设模型怎么填密钥、自定义端点怎么加、本地模型怎么指过去，以及上下文预算和用量怎么看。

## 在哪配置

两个入口，通向同一页：

- 顶栏右侧的**密钥**按钮；
- 顶栏页签**设置**，再在左侧导航里选**模型配置**。

「模型配置」区块里有三块内容：**自定义模型**列表、**内置模型密钥**列表，以及 Responses API 模式开关。每一行模型后面都跟着一个「最大上下文」（滑杆 + 精确数字框 + 探测窗口按钮，见下文「上下文预算怎么定」）。

## 预设模型

SLATE 自带一份模型清单，分四组出现在输入区的模型下拉框里：

| 分组 | 包含 |
|---|---|
| 国际模型 | GPT 系列、Claude 系列、Gemini 系列 |
| 国产模型 | DeepSeek、Kimi、Qwen、GLM、Doubao、MiniMax、ERNIE |
| 本地模型 | 内置一条本地模型条目，供 Ollama / LM Studio 使用 |
| 自定义 | 你自己添加的端点 |

下拉里每一条前面的圆点是密钥状态：**已配置**为实心，**未配置**为空。鼠标停在选项上还能看到模型 ID、接口地址与该模型是否支持 Responses API。

圆点旁边是这一家的品牌 mark。内置模型和你自己添加的模型走同一套判定：按**模型名称**认，名字里认不出品牌时才看**接口地址**——所以 `deepseek-r1:1.5b` 跑在本机 Ollama 上仍然画 DeepSeek 的标，而不是 Ollama 的。认不出来就什么也不画，宁可留白，也不会拿别家的 logo 顶上去。mark 是随包分发的各家官方图形：47 家有彩色原件的直接按品牌自己的颜色画，另外 11 家（OpenAI、Anthropic、xAI、Ollama、Z.ai 等）包里只有单色版，画一枚中性灰。两支都不跟主题走——「扩展 → 外观」里挑的墨色与强调色染不到品牌色，明暗模式切换下也不会糊成一团黑。GLM（智谱）旁边画的是 **Z.ai** 的标：这家把对外标识换成了 Z.ai，我们跟着新标走，包里它只有单色版。

具体有哪些型号以你界面里列出的为准。给某个模型配密钥的步骤：

1. 在「内置模型密钥」里找到它。
2. 在输入框里粘贴 API Key，点右侧的保存按钮。
3. 已配置的输入框会提示「已配置」；清空内容再保存即可删除该密钥。

## 添加自定义模型

只要你的服务商提供 OpenAI 兼容接口，就能接进来。

1. 点「模型配置」右上角的 **+ 添加模型**。
2. 填写这些字段：

| 字段 | 说明 |
|---|---|
| 模型名称 / ID | 服务商要求的模型标识，也是下拉框里显示的字 |
| 请求模式 | OpenAI 兼容、Anthropic、或 curl 直连三种 |
| Base URL | 你的接口地址 |
| API Key | 可选；本地或免鉴权的端点可以留空 |
| Context Window | 该模型能容纳的上下文规模 |

3. 点「添加」保存，它会出现在模型下拉框的「自定义」分组里。

:::tip 先别急着换模型
新加一个端点后，先去 **设置 → API 测试** 打一发最短请求。通了再把它设成常用模型，能省下不少「是模型不行还是配置写错了」的来回猜。
:::

## 使用本地模型

想让推理完全留在本机，用 Ollama 或 LM Studio 都可以。

- 模型清单里已经有一条**本地模型**条目，默认指向本机 Ollama 的兼容地址（默认端口 11434）。
- 用 LM Studio 时，把它显示的监听地址填进该条目的 Base URL。
- 端口如果你自己改过，请按实际监听的端口填写。
- 本地模型不校验 API Key，下拉里会标注为本地模型。

:::note 本机地址指的是什么
本地模型的地址指向你自己的电脑，不需要外网。所以断网也能用它；反过来，模型跑不跑得动、上下文能开多大，取决于你这台机器的显卡与内存。
:::

## API Key 与数据安全

- API Key 保存在本机（本地加密存储），只用于调用你自己配置的模型。
- 密钥不会写进对话记录，也不会随项目文件一起落到你的工作目录里。
- 备份导出时可以一并带走，导入到新机器后继续使用。

:::warning 别把密钥写进会公开的地方
不要把 API Key 抄进项目文件、笔记或截图里。它会随代码仓库、聊天记录一起传播出去；一旦怀疑泄漏，立刻到服务商后台吊销并重新生成一把。
:::

## 上下文预算怎么定

每个模型都有自己的上下文预算。开得越大，单次请求能带的材料越多，消耗也越高。

- 模型配置里每一行的**最大上下文**由三件组成：按这个模型的窗口生成的滑杆、一个精确数字框、一个**探测窗口**按钮。
- 选**自动**时按这个模型自己的标称窗口 ×0.8 取值，不再吸附到公共档位。只有 8K 窗口的本地模型因此拿到 6553，而不是凑不满最低一档、把整个窗口占满到没地方写回复。
- 数字框保留你填的精确值（131072 就是 131072），只在 1K–4M 区间内夹取；选的值超出这个模型的窗口时会自动封顶，读数上会同时显示你选的值与实际生效的值。
- 本地与自定义端点（Ollama / llama.cpp / vLLM / OpenAI 兼容）可以点**探测窗口**，直接问这台服务器它实际能吃多少。探到的值单独存一张覆盖表，参与自动档与封顶，随时可一键清除，回到端点自带的值；探不到时如实说明「这个端点没有暴露上下文窗口」，不会替你编一个数。
- 既没填标称窗口、也探测不到的模型，自动档才回落到全局的「上下文 Token 上限」（在 **设置 → 上下文与项目** 里改）。

自动压缩的触发阈值与界面上那根上下文条，都按同一个数字计算，不会出现「条满了却不压缩」的错位。上下文条可以直接点，点一下跳到对应模型的这一行。

## 思考强度怎么选

输入框左侧的档位胶囊管的是「这一场让模型想多久」（自动 / 关 / 低 / 中 / 高），每个对话各存一份。刻度不是一张固定表——SLATE 按端点能力分了九类，弹窗里只出这个模型真能接的档：

- 强制思考的模型没有「关」这一档，最低就是「低」。
- 只能整体开关、不能调档的端点，刻度旁注明「低 / 中 / 高都按开」。
- 不支持思考的模型相关刻度直接置灰，并写明原因；切到该模型那一刻弹窗里会提示。
- 上游若以 400 点名这个字段，SLATE 会剥掉它重发一次——最坏是这次档位不生效，而不是模型用不了。
- 档位下方的小字（随墨 / 清墨 / 淡墨 / 浓墨 / 焦墨）只是浓淡提示；拖动时只预览，松手才生效并落盘。

## Responses API 模式

「模型配置」里有一个开关：**启用 Responses API 模式**。它用新版 API 格式发请求，仅部分模型支持。

- 默认关闭，按现有格式发送请求即可正常工作。
- 只有当你明确知道自己的端点支持 Responses API、并且需要它的能力时才打开。
- 不确定就不开；开错了通常表现为请求被上游拒绝。

## 轻量模型与重型模型的分工

不同档位的模型可以各司其职，既省钱又不牺牲结论质量。

| 场景 | 分工 |
|---|---|
| AI 团队辩论 | 轻量模型负责讨论与发声，重型模型负责最终决策 |
| AI 辅助功能 | 压缩摘要、记忆蒸馏、代码理解、命令说明等十几项，逐项可关、可单独指定模型 |
| 自动推进审阅 | 在「自动推进」区块里单独指定审阅模型 |

这些开关与指定入口都在设置里，逐项说明见[设置与安全审批](./19-settings.md)。

## 切换模型与用量显示

- **切换**：在输入区的模型下拉框里选，只影响这一场会话；下拉框最后一项是「+ 自定义模型…」，可以就地新增。
- **单条用量**：每条回复都会标出所用模型与 Token 用量。
- **本场用量**：标题栏下方的用量信息栏反映屏幕上这一场；左栏的**总结**页签给出一场的汇总。
- **累计用量**：**设置 → 用量统计**，看全部对话的累计消耗。

同一时刻可能有多场会话在跑，每场各记各的账，用量条只反映你眼前这一场。

## 常见问题

**密钥填了但还是报错**

去 **设置 → API 测试**，选中出问题的模型，点「开始测试」。这条请求走的是真实对话的同一条链路，能直接区分「密钥不对」「地址不对」「余额不足」还是「模型名写错了」。

**下拉框里没有我要的模型**

用「+ 添加模型」按自定义端点接入即可，不必等清单更新。

**列表显示「暂无内置模型」**

说明内置清单这次没取到。可以先手动添加自定义模型顶上，再对照[常见问题](./20-faq.md)排查。
