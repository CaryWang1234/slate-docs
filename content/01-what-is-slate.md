SLATE（砚）是一台跑在你自己电脑上的 AI 协作调度台。它把粗糙的灵感研磨成结构化方案，再决定是自己动手执行，还是产出一份高质量 Prompt 交给外部的 Coding Agent。

这页帮你建立整体印象：它解决什么问题、有哪些能力、适合谁用。

## SLATE 是什么

SLATE 是本地优先的 AI 协作工具，专注于提示词工程、上下文管理与项目灵感整理。它把主流大模型、内置工具、团队辩论、工作流、白板式逻辑链整合在一个界面里。

**它有两副面孔，你可以按场景选：**

1. **自己动手** —— 直接驱动内置工具完成任务：读项目、写文件、跑命令、生成文档与图表。
2. **产出 Prompt** —— 把上下文、约束、验收标准整合成一份可交付的 Prompt，交给 Claude Code、Codex、Cursor 这类外部 Coding Agent 执行。

:::tip 一句话理解
灵感负责发散，SLATE 负责把灵感收成一份能落地的方案。
:::

## 从灵感到落地

一个想法从模糊到交付，通常会走成这样：

1. **磨墨** —— 把一句粗糙想法交给磨墨模式，AI 追问目标、受众、交付物与验收标准，最后收成一份墨稿。
2. **推演** —— 把墨稿投到白板，卡片加连线把依赖与顺序摆清楚；也可以先让 AI 团队辩一轮。
3. **执行** —— 打开目标模式，让模型按六阶段自主推进、逐项验证，直到全部了结才收口。
4. **外送** —— 如果这活更适合外部 Coding Agent，用提示词工厂把上下文与约束整合成一份 Prompt 交出去。

每一步都可以只用其中一环，不必走完全程。

## 它解决什么问题

只给你一个聊天窗口的 AI 工具，意味着下面四件事都得你自己扛。SLATE 把这些活接了过去。

| 常见麻烦 | SLATE 的做法 |
|---|---|
| 上下文管理 | 会话历史全文搜索与导出、超阈值自动压缩、长期记忆跨会话召回、知识库按需注入 |
| 提示词工程 | 提示词工厂把宪法、上下文、约束整合成一份 Prompt；磨墨模式把模糊想法问成结构化任务书 |
| 项目级操作 | 打开项目后可读文件、改代码、跑命令、查 Git 状态，不必复制粘贴来回搬 |
| Token 消耗 | 智能压缩、分级调用、轻量模型负责讨论重型模型负责决策、AI 辅助功能逐项可关 |

## 核心能力一览

| 能力 | 是什么 | 一句话价值 |
|---|---|---|
| 多模型对话 | 国内外主流模型 + 任意 OpenAI 兼容端点 + 本地模型，统一在一个对话界面 | 换模型不用换工具 |
| Agent Autopilot 与目标模式 | 识别到查项目、改文件、跑命令、排查 bug 这类请求就自动进入多轮 Agent 循环；目标模式是显式六阶段、更强闭环的版本 | 不用反复发「继续」，干完自己收口 |
| 磨墨模式 | 一句粗糙想法，AI 三段式追问后研磨成任务书 | 想法还糊的时候，先把它磨清楚再动手 |
| MCP 工具与技能 | 内置三十多个工具，另可用 `SKILL.md` 扩展新能力 | 模型能真的操作你的文件与命令行 |
| Actions 流程说明书 | 把「干某件事的必要流程」写成一份说明书，模型按流程推进 | 重复流程沉淀一次，之后照着走 |
| 专家包 | 人格 + 规则 + 知识 + 技能打包成一个包，可导入导出 | 一个领域专家配一次，处处复用 |
| AI 团队与工作流 | 多角色多轮辩论（提案 / 反驳 / 决策），以及 DAG 工作流流水线 | 重要决策先辩一轮，再动手 |
| 白板 | 卡片加连线整理思路，工具执行自动记成步骤卡 | 把推演过程摊在一屏上看 |
| 记忆与知识库 | 自动沉淀对话要点、跨会话召回，对话结束还能捕获技术洞察 | 不用每次重新交代背景 |
| 提示词工厂 | 项目上下文、任务描述、约束一键整合为可交付 Prompt | 交给外部 Coding Agent 的 Prompt 从这儿出 |
| 移动端遥控 | 手机 / 平板浏览器打开局域网地址即进入专属移动端界面 | 离开电脑也能看进度、下指令 |

## 它和外部 Coding Agent 的关系

SLATE 不替代 Claude Code、Codex、Cursor，它站在它们前面。

- 直接在 SLATE 里干活：适合需要读项目、跑命令、反复验证的任务，全程不用离开这个界面。
- 在 SLATE 里备料：适合交给外部 Agent 的大改造。它先把项目上下文、约束条件、验收标准整理成一份结构清晰的 Prompt，你复制走即可。

两种用法共用同一份记忆、同一份项目宪法与同一批专家包。

## 设计原则

- **纯黑白灰视觉** —— 界面本身不用彩色渐变与装饰性阴影，注意力留给内容；唯一带颜色的是各家模型的品牌 mark，按官方原色画，不跟主题改。
- **原生技术栈** —— 零 npm、零构建工具，界面即文件。
- **本地优先** —— 所有数据存在本机，不经过任何云端中转。
- **Token 节约** —— 智能压缩、分级调用、静默处理，不浪费每一次请求。
- **永不卡死** —— 空闲看门狗、零内容自动重试、请求超时、界面兜底多层防线。

## 你的数据在哪里

对话历史、长期记忆、知识文档、专家包、动作流程、定时任务与各项设置，全部以本机文件形式保存。API Key 保存在本机（本地加密存储），只用于调用你自己配置的模型。

具体包括：

- 每一场对话与每一条消息；
- 长期记忆条目与用户画像；
- 知识文档与文档归档；
- 自建技能、专家包、流程说明书；
- 定时 / 事件任务与执行记录；
- 模型、审批、主题、排版等各项偏好。

这些内容的备份、恢复与清理，统一在设置里的数据相关区块处理，也可以一键导出成一个文件换机迁移。

:::note 关于联网
SLATE 本身是本地应用，但模型推理发生在你选择的模型服务商那里。所以对话时需要能访问你配置的模型端点；内置的联网搜索、网页抓取、更新检查也各需要网络。
:::

## 适合谁

- 手上有想法、但不知道怎么把它写成可执行方案的人。
- 已经在用 Claude Code / Codex / Cursor，想先在本地产出一份高质量 Prompt 的人。
- 需要一个长期记住项目背景、跨会话不忘事的 AI 工作台的人。
- 在意数据留在本机、不想把项目内容交给云端协作平台的人。
- 习惯本地模型（Ollama / LM Studio），想把本地与在线模型放在同一个界面里的人。

## 不适合谁

- 想找一个替代 IDE 的人：SLATE 负责协作者与调度，不提供编辑器、调试器、补全等完整 IDE 能力。
- 想找云端多人协作平台的人：SLATE 是本机应用，没有账号体系与云端共享空间。
- 希望开箱即用、不想自备 API Key 的人：模型额度需要你自己准备。
- 想用它做大模型本身的人：SLATE 是调度台，不是训练框架。

## 术语速查

| 术语 | 含义 |
|---|---|
| Agent Autopilot | 默认的自动推进层：识别到环境操作类请求就自动进入多轮 Agent 循环，干完自动收口 |
| 目标模式 | 显式开启的强闭环模式，按「目标 → 计划 → 执行 → 验证 → 汇报 → 追溯」六阶段推进，轮数预算更大 |
| 磨墨 | 把粗糙想法研磨成结构化任务书的过程，三段式追问，最多十轮 |
| Actions | 流程说明书，写明「干某件事的必要流程」，模型按需读取后照流程推进 |
| Skill | 用一份 `SKILL.md` 描述的可插拔能力，聊天中提及即注入上下文 |
| MCP | 模型调用外部工具的协议层，SLATE 内置工具与外部 MCP Server 都由此接入 |
| 专家包 | 人格、规则、知识、技能打包成的可分发配置 |
| 砚流 | 模型逐 token 写出工具参数时，界面实时演出参数成形过程的预览机制 |
