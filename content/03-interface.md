这页把主界面从头到尾认一遍，让你知道每个入口在哪、点下去会发生什么。

先记住一句话：SLATE 由**一个顶栏 + 四块工作区**组成，每次只显示一块，点顶栏页签即切换。

## 整体布局

| 区域 | 位置 | 能干什么 |
|---|---|---|
| 对话 | 顶栏页签「对话」 | 与模型对话、跑 Agent 循环、看工具卡片与任务清单、管理会话历史 |
| 黑板 | 顶栏页签「黑板」 | 卡片加连线理思路，切换 Git 树 / 流程 / 看板 / 纲要 / 工作流等视图 |
| 扩展 | 顶栏页签「扩展」 | 管理模型能用什么：技能、内置工具、模式、新功能（自产工具）、MCP、专家包、Actions 七栏 |
| 工厂 | 顶栏页签「工厂」 | 把项目上下文、任务、约束整合成一份可交付的 Prompt |
| 设置 | 顶栏页签「设置」 | 模型密钥、上下文、审批模式、备份、局域网与关于 |

设置是一页独立的配置区，不算工作区。

:::note 「三栏」指的是对话页内部
习惯上说的「三栏」不在顶栏，而是**对话**这块工作区自己分出来的三列：**左侧边栏**放项目、任务与总结三页签，**中间消息流**放对话内容与输入框，**右缘**按需滑出任务清单栏、后台任务面板与墨迹面板。团队对话是消息流里的模式切换，不是第四块工作区。
:::

:::note 建议的认路顺序
界面元素比较密集，第一次用建议按这个顺序逛一遍：**顶栏 → 四块工作区 → 对话区左侧边栏 → 消息区 → 输入区**。每个位置停一下，看看有什么按钮就够了，不必一次记住全部。
:::

## 顶栏

顶栏横贯整个窗口，分三段：

- **左侧**：应用标识（砚 · SLATE）。
- **中央**：五个页签 —— **对话 / 黑板 / 扩展 / 工厂 / 设置**，用来切换工作区。
- **右侧**：四个圆形按钮。

| 顶栏按钮 | 作用 |
|---|---|
| 密钥 | 直接跳到设置里的「模型配置」，管理模型密钥 |
| 遥控 | 直接跳到设置里的「局域网遥控」，查看手机端访问地址 |
| 明暗 | 一键切换亮色 / 暗色主题；自定义主题开着时会变淡并锁定，点它会说明原因 |
| 设置 | 打开设置页 |

发现新版本时，提示横幅会出现在顶栏正下方，带下载入口与「忽略该版本」。

:::tip 找不到某个设置
顶栏右上的「密钥」和「遥控」是两份快捷方式，点下去打开的还是同一个设置页，只是自动滚到对应区块。所以记不住位置时，从顶栏这两个按钮进最快。
:::

## 左侧边栏

对话区左侧是边栏，顶部有三个页签：**项目 / 任务 / 总结**。边栏与消息区之间的分隔条可以拖动，用来调整宽度。

### 项目页签

- 顶部是当前项目名与操作入口；项目是工作区时会有「工作区」标记。
- 下面是项目文件树，点文件可以在下方直接预览内容。
- 在册项目列表里可以切换项目，也可以打开一个新的目录。

### 任务页签

这里是你所有会话的入口：

| 元素 | 说明 |
|---|---|
| ＋ 新建对话 | 开一场新会话，快捷键 `Ctrl + N` |
| 排序下拉 | 最近更新 / 按项目 / 按状态 / 创建时间 / 按用量 |
| 管理 | 批量管理历史会话 |
| 搜索框 | 搜索历史会话，命中即显上下文摘录 |
| 会话列表 | 每条会话带自己的状态标志 |

**状态标志一共四种**，记的是「上一场是怎么结束的」：

| 标志 | 含义 |
|---|---|
| 需要操作 | 上一场被停止，或还有下一步等你决定 |
| 出错 | 上一场以失败告终 |
| 进行中 | 这一场此刻真的在生成，图标带呼吸动画 |
| 已完成未查看 | 跑完了但你还没点进去看过；点进会话即清除 |

排序偏好跨设备同步；状态标志只在你自己的机器上流转，不会跑到别的设备。

### 总结页签

把当前这一场会话的用量汇总在一处，方便你看这场花掉了多少。

## 中间对话区

消息区的标题栏左侧是**对话 / 团队**两个模式切换：日常问答、写代码在「对话」里；要让多个角色辩论或跑工作流，切到「团队」。

标题栏右侧是一排动作按钮：

| 按钮 | 作用 |
|---|---|
| 手动压缩上下文 | 不等自动阈值，立刻把历史对话压缩一次 |
| 记忆与画像 | 查看和管理长期记忆、用户画像 |
| 专家包管理 | 导入、导出、编辑专家包 |
| 提示词素材 | 管理可复用的提示词片段 |
| 任务清单 | 收起或展开消息区右侧的任务清单栏 |
| 后台任务 | 查看后台终端任务的状态与输出 |

标题栏下方是一条用量信息栏，显示这一场会话的 Token 消耗。

**消息区主体**从上到下依次是：

- 对话消息流，每条回复带模型名与用量；
- 工具调用卡片，显示工具名、参数与执行状态；
- 思考过程折叠面板，模型推理时实时展开，思考完成后自动折叠；
- 右侧的任务清单栏，大任务跑起来时逐条显示进度，可整栏收起；
- 后台终端任务面板与磨墨墨迹面板，只在对应场景出现。

## 输入区

输入区在消息区底部，由一行多行输入框加一行工具栏组成。

**输入框**：支持多行。`Enter` 发送，`Shift + Enter` 换行。

**工具栏左侧**，从「＋」按钮开始依次是：

| 控件 | 说明 |
|---|---|
| ＋ 模式菜单 | 集中所有模式入口，见下一节 |
| 回复模式 | 输入框左下的模式胶囊，决定这一场怎么干活：内置智能 / 对话 / 经济 / 狂暴四档，各有图标与颜色，也可是自定义模式；切换只改这一场，默认档与自定义模式在「扩展 → 模式」里管 |
| 审批模式 | 这一场什么时候该停下来问你，四档可随时改：手动审批 / 自动审批 / 完全访问（胶囊标红）/ 夜间模式；选到「夜间模式」就什么都不问了 |
| 添加附件 | 附带文件一起发送 |
| 专家包 | 选一个专家包，人格与规则全程生效 |
| 模型 | 当前这一场用哪个模型 |
| 推理强度 | 按模型能力给出可选档位，档位下方标出对应墨色；这个模型接不住的档位会置灰并写明原因 |

**工具栏右侧**依次是优化提示词、语音输入与发送。生成过程中，发送按钮会变成**停止**——点下去是真的取消，不是只让界面安静下来。

点**优化提示词**（语音按钮左边那颗星）会把输入框里写了一半的草稿交给当前模型改写一遍，但改写结果不直接进输入框：先与原文并排放在弹窗里给你比对，只有点**采用**才写回。点**保留原文**、按 Esc、点弹窗外面，都算不采用，输入框一个字都不会变。等结果的那几秒如果你又改了草稿（包括语音实时写进去的字），这次结果会被放弃，不会盖掉你新写的内容。用哪个模型可以在[设置 → AI 辅助功能](./19-settings.md)里单独指定，关掉后一次请求都不发。

### ＋ 模式菜单

点输入框左侧的「＋」，弹出「模式与功能」，里面是四行模式加一组提及：

这个菜单钉在「＋」按钮的正上方，和同一条工具栏上的审批模式、推理强度是一个手感：再按一次「＋」、点菜单以外的任何地方、或按 Esc，都会把它收起。

- **磨墨模式** —— 把粗糙想法研磨成任务书，行内小字会显示当前研磨进度。
- **头脑风暴** —— 一个开关。
- **目标模式** —— 一个开关，显式六阶段强闭环。
- **定时任务** —— 创建与管理定时 / 事件任务。
- **提及（@ 前缀）** —— 技能 / 工具 / MCP / 文件，点任意一项会弹出对应的候选列表，选中后以提及的形式写进消息。

## 主题与外观

顶栏的「明暗」按钮一键切换亮色与暗色，切换立即生效。这个偏好跟着你的设置一起同步，换一台设备访问同一个 SLATE 也是同一个主题。

想彻底换一张脸，去 **设置 → 自定义主题**：四个源色（底色 / 面板 / 正文 / 强调）加正文与代码两套字体（也能导入你自己的字体文件），再加板块透明度、一张本机背景图与遮罩浓度，10 套基础预设可以直接点；装了 Wallpaper Engine 的话还能把它正在用的那张壁纸预览图取过来当背景。其余三十几个颜色令牌由这四个源色推导，推导时按对比度兜底，所以配色不会糊成一片读不清。

开启自定义主题期间明暗切换会被锁住——两套色同时说话只会互相矛盾。按钮不会变灰，点下去会告诉你为什么没换，以及去哪里关掉它。相关细节见 [设置与安全审批](./19-settings.md)。

## 移动端会自动换一套界面

用手机或平板浏览器打开局域网地址时，SLATE 会自动进入移动端界面，底部换成五个 Tab。桌面浏览器访问仍然得到完整桌面界面。详见[移动端遥控与局域网访问](./18-mobile.md)。

## 新手引导

首次启动会弹出一份引导，用卡片介绍最常用的几个入口。想重看，去 **设置 → 关于**，点「新手引导」按钮。
