这一页说明设置页里各分区分别管什么，以及 SLATE 动手之前会怎么征求你的同意。设置页从顶栏「设置」进入，左栏导航由页面上的区块现场生成、与区块标题一一对应，顶部还有一格搜索：输入关键词只留下含这个词的区块并把命中的那一行描出来，回车或点击直接跳过去，清除后原样回来。

## 设置页分区总览

| 分区 | 管什么 |
|---|---|
| 模型配置 | 添加自定义模型与内置模型密钥、配置 Base URL、每个模型一行「最大上下文」（滑杆 + 精确数字框 + 探测窗口）、可选启用 Responses API 模式 |
| API 测试 | 用一条最短请求验证某个模型的密钥与端点是否可用 |
| 用量统计 | 全部对话的累计 Token 用量，随对话自动更新 |
| 上下文与项目 | 上下文 Token 上限、单次输出上限、文件写入是否自动确认、项目宪法 |
| 自动推进 | 回复疑似停顿时的补调策略，以及 Continue Autopilot |
| AI 辅助功能 | 对话以外的耗 Token 功能逐项开关与单独选模型 |
| 通知 | 大任务结束时的提示音与系统通知 |
| 后台任务 | 长耗时命令走独立通道后的唤醒开关：任务有消息时自动叫醒模型、每个对话最多自动续跑几次 |
| 多任务与项目 | 切走会话时是否让它后台继续跑、同时最多跑几场 |
| 通用 UI | 极简 Codex 风格布局开关（实验性） |
| 自定义主题 | 配色（四个源色推导整套）、字体（系统字体族 + 导入自己的字体文件）、板块透明度、背景图与遮罩浓度，可从 Wallpaper Engine 取当前壁纸；10 套基础预设，开启时明暗切换锁定 |
| 联网搜索 | 默认搜索引擎、网页 JS 渲染策略 |
| 图片生成 | 生成类工具的模型与 API Key |
| 视频生成 | 生成类工具的模型与 API Key |
| 审批模式 | 每个对话默认的审批档位 |
| 数据备份与恢复 | 备份导出与导入 |
| 会话归档 | 从「任务」栏归档起来的会话，在这里逐条恢复或删除 |
| 存储空间 | 存储占用与管理 |
| 局域网遥控 | 遥控地址与二维码 |
| 打字小游戏 | 顺手测手速，题库可自定义 |
| 关于 SLATE | 版本、检查更新、新手引导、官网与 GitHub |

:::note 技能与 MCP 不在这一页
「模型能用什么」——技能、内置工具、回复模式、新功能（工具工厂自己生产的工具）、MCP、专家包、Actions——全在顶栏「扩展」那一页管理，设置页不再兼做能力清单。详见 [内置工具与技能](./08-tools-skills.md)。
:::

## AI 辅助功能

除对话、团队对话与提示词工厂之外，每一处会自己去找模型要结果的功能都在这里挂号，共 15 项。每一项都能单独关掉，也能单独指定模型；不指定时跟随当前主模型。

| 功能 | 触发方式 | 关掉后 |
|---|---|---|
| 上下文压缩摘要 | 自动 | 不再自动压缩，手动点「压缩」也不发请求 |
| 记忆自动蒸馏 | 自动 | 不再自动沉淀长期记忆 |
| 记忆手动提取 | 手动 | 记忆面板的「从当前对话提取」不再发请求 |
| 对话洞察捕获 | 自动 | 不再自动生成灵光卡片 |
| 自动会话标题 | 自动（首轮跑完） | 新会话保持「首条消息前 30 字」的占位标题，不再起名 |
| 代码理解文档 | 手动 | 扫描项目后不再生成导览与规则手册 |
| 代码审查 | 手动 | 只取 diff，不再做四维度审查 |
| 黑板 AI 整理 | 手动 | 黑板内容不再交给模型重排 |
| 提示词优化 | 手动 | 输入框那颗按钮照常点，但不再发请求，只提示一句「已关闭」 |
| 子代理并行 | 模型调用 | 工具从工具目录消失，模型看不到也就不会调 |
| 高危命令目的说明 | 自动 | 审批弹窗照常拦，只是不再生成那句命令目的 |
| 团队工作流执行 | 手动 | 工作流不再逐节点请求模型 |
| 定时与事件任务 | 自动 | 任务不再执行，触发记录仍保留 |
| AI 图片生成 | 模型调用 | 工具从工具目录消失 |
| AI 视频生成 | 模型调用 | 工具从工具目录消失 |

列表上方会实时汇总「共 15 项，已关闭 N 项」。关掉即一次模型请求都不发，这是最直接、也最可控的节流手段。

:::tip 省 Token 的第一手段
逐项关掉你根本用不上的功能，比事后压缩上下文更省。日常只做对话与工具执行的话，压缩、蒸馏、洞察、图片、视频这些都可以先关掉，需要时再打开。
:::

## Continue Autopilot

在「自动推进」区块里，默认开启。它的作用是：Autopilot 或目标模式的轮数用完了，并不等于活干完了。如果末轮还在执行工具，就把上限往后推 8 轮（最多推 3 次）让手上的活做完；如果末轮空手停笔，就把清单里剩下的项念回给模型，催它继续推进或明确写下任务完成。

散场之后还有一层：这一场不是因为「完成」退出的、而是因为轮数用尽停下的，只要它不在手动审批档（自动审批 / 完全访问 / 夜间模式），SLATE 就替你按下那颗「继续跑完」——等这一场彻底空下来（压缩、蒸馏这些收尾还要占几秒）再发，一场最多自动续两次，界面 toast 会写明「轮数用尽 · 已自动续跑（第 1/2 次）」。手动审批档不在此列：那一档的语义就是每一步都要人点头，所以它照旧只把「继续跑完」条挂出来等你。额度用尽、或续跑没接上时，那颗手动按钮仍然在原地。

关掉它就回到旧行为：轮数用完即停，需要你自己说一声继续。这个开关只留在本机，不随局域网遥控同步。相关机制见 [Agent Autopilot 与目标模式](./06-autopilot.md)。

## 任务完成通知

大任务结束时（目标模式、团队讨论、工作流跑完）可以给你一个提醒，两个开关互相独立：

| 开关 | 默认 | 说明 |
|---|---|---|
| 任务完成时播放提示音效 | 开启 | 短促提示音，无需任何授权 |
| 任务完成时发送系统通知 | 关闭 | 需要浏览器授予通知权限，未授权时区块下方会给出提示 |

两个都关掉也不影响任务本身，只是不再提醒。适合把长任务挂后台、你去做别的事的场景，开着能在收工时立刻回到屏幕前。

## 主题与语言

- **明暗主题**：用顶栏的「明暗」按钮一键切换，移动端在顶部状态条右侧也有同一个按钮。选择会跨设备同步，手机上切了，电脑上刷新即一致。
- **自定义主题**：这一区块只填四个源色——底色、面板色、正文色、强调色——其余三十几个颜色令牌由它们推导出来。为什么不逐个开放：令牌逐个改，很容易改出一版正文读不清的四不像，而源色只有四个，推导时按亮度分深浅两套、按对比度兜底，配色就必然成套。代码块在任何配色下都保持深底亮字，危险 / 完成 / 需要操作三种状态色整组跟随底色亮度切换，不跟着你的强调色走，否则红绿含义就认不出来了。模型品牌 mark 也不参与这套推导：有彩色原件的按品牌原色画，没有的固定一枚中性灰，你挑的墨色染不到它们。
- **10 套基础预设**：纸墨、夜金、雾蓝、深海、松墨、苔绿、陶土、暮紫、石墨、铅字。点预设等于把四个源色一次填好，之后你照样可以只改其中一格；一改色板，这一套就不再是那个预设，高亮会自动清掉。
- **字体**：正文与代码各一个下拉，候选先列系统里已有的字体族（含「跟随系统」）；下拉下面那颗「导入字体」把自己手上的 .woff2 / .woff / .ttf / .otf（单个文件、16MB 以内）导进来，导入后它和系统字体一样出现在两个下拉里，清单逐条报出大小并可单独移除。字体文件只存在本机 `data/theme/fonts/`，不进对话记录、也不复制到另一台设备；只导入一个字重时，粗体与斜体由浏览器模拟。字体栈末尾带通用族兜底，换一台没装也没导入这字体的机器不会糊成默认衬线。
- **板块透明度**：一个「板块不透明度」滑杆（55%–100%，默认 100%），管的是面板、卡片、输入框与助手气泡这一层底色的不透明度。100% 就是实色，行为与旧版逐像素相同；调低会透出页面底色，铺了背景图时也能透出图。你自己的气泡和代码块始终保持实色，正文不会因此读不清。它和遮罩浓度各管一层：板块取两者里更低的那一档，不会两层各降一次把面板洗没。
- **背景图**：挑一张本机的 PNG / JPG / GIF / WebP（不超过 4MB），只有这一张存在本机的数据目录里，不随局域网遥控上传，也不进备份。铺上之后界面会变为半透明骑在图上，「遮罩浓度」滑杆调的就是底色的不透明度（40%–95%，默认 72%）：低于 40% 正文就直接骑在图上，高于 95% 等于没有图。填图与摘图都走顶栏那个「移除」按钮，摘掉后底色回到实色。
- **Wallpaper Engine**：装过 Wallpaper Engine 的机器上，这里多一颗「取当前壁纸」——把它正在用的那张壁纸的预览图取过来当上面的背景图，旁边「重新检测」用来在它被关掉或换过目录后重新认一次。这一步是只读的：SLATE 只看 Wallpaper Engine 写在自己目录里的配置和 preview 图，不启动它、也不改它的任何设置。它换了壁纸这里不会跟着换，要再点一次；视频与场景壁纸取到的是那张静态预览图，只有动态预览时才取 gif（那张会在界面后面一直动）。状态那一行只报壁纸名、文件大小和来源屏号，不报本机的绝对路径。
- **开启自定义主题时不能切明暗**：整套令牌是从那四个源色推导的，再切一次明暗底版只会两套色互相矛盾。这时明暗按钮会变淡并写明「锁定」，点它不会换色，而是弹一句提示告诉你去哪关掉自定义主题；移动端同样。把自定义主题关掉，一切痕迹（注入样式、颜色、字体、背景图）当场摘干净，明暗切换随即复活。
- **界面语言**：安装时选择简体中文或 English，应用运行中不提供切换入口。English 界面翻的是界面文案本身——按钮、区块标题、输入框里的灰字提示（placeholder）与悬浮提示都算；模型生成的内容与你自己输入的文字、以及你贴进对话的代码始终原样呈现，不会被翻译。品牌字标「砚」也保持原样。
- 想换语言，重新运行安装程序并选择另一种语言即可；如果只是想让某台设备换个语言，同样以安装时选定为准。

:::note 背景图与导入的字体只在本机
背景图和 `data/theme/fonts/` 里那些字体文件都只存在这台机器的数据目录里，不写进备份、也不跟着同步。换一台设备或重装后，同一个开关会显示「本机还没有背景图」「本机还没有导入的字体」，重新挑一份即可——配色、透明度与字体选择不受影响，照常生效。
:::

## 关于区块

「关于」把版本与更新相关的操作集中在一处：

- **当前版本**：显示你现在运行的是哪一版。
- **检查更新**：启动时也会自动检查一次。发现新版本会显示当前版本与最新版本、更新说明摘要，以及「下载更新」「更新说明」两个按钮，都会用系统浏览器打开。
- **新手引导**：忘了三栏工作台怎么用，点这里重看一遍。
- **项目链接**：官网与 GitHub 仓库，同样用系统浏览器打开。

## 安全与审批

SLATE 遵循「零自主修改」准则：你说改，它就真去改；你不说，它绝不擅自碰。为了让这条准则落地，动手前会经过几道门。

**审批模式**（「设置 → 审批模式」可设默认档，单个对话还可在输入框的审批模式选择器里随时改，改过的那一场就不再跟着默认档变）：

| 模式 | 语义 |
|---|---|
| 手动审批 | 执行命令与访问网络都先问过你 |
| 自动审批 | 只有命中高危规则的才问，其余直接放行 |
| 完全访问 | 命令与联网都不问了；但模型缺条件时仍会弹选择题问你一句。灾难级命令照样由后端拦死，这一档在选择器上标红 |
| 夜间模式 | 全托管：命令、联网都不问，连模型「缺条件时想问你一句」也不问——它自己选定方案继续。适合挂着跑完再看 |

夜间模式这一档对用户的承诺是「没有任何东西在等人」：审批弹窗不会等你批准，选择题也不会等你回来选。因此灾难级命令仍然在任何模式下被后端强制拦死——那一道不是「问」，是「不许」。

**高危命令**采用写死规则判定，前后端双层拦截：前端拦一次，后端再独立拦一次，绕过界面也拦得住。命中后弹窗会写清命令原文与触发的规则，并附一句由模型生成的命令目的说明，由你决定批准还是拒绝；被拒绝时，模型会收到明确的拒绝理由，并被要求不要重试。灾难级命令（如清空根目录、格式化磁盘）在任何模式下都无条件禁止。

**文件编辑**走差异预览：改动以差异卡片呈现，接受才落盘，拒绝则不写入。设置里有一个「自动确认文件创建/修改」开关，默认开启——也就是常规写入无需你每次点接受；想每一笔都亲自过目，把它关掉即可恢复逐笔确认。

| 操作 | 需要审批 | 自动放行 |
|---|---|---|
| 执行终端命令 | 手动审批与自动审批下按规则确认 | 完全访问与夜间模式 |
| 启动后台任务 | 同上 | 完全访问与夜间模式 |
| 联网搜索、抓取网页、浏览器自动化 | 手动审批下逐条确认 | 自动审批、完全访问与夜间模式 |
| 模型缺条件时向你提问（选择题弹窗） | 手动、自动审批与完全访问下等你选完再继续 | 夜间模式（改为让模型自行拍板） |
| 读取文件、浏览目录、搜索代码等只读操作 | 不经审批 | 任何模式 |
| 创建与编辑文件 | 取决于「自动确认文件创建/修改」开关 | 该开关开启时 |
| 灾难级命令 | 任何模式都无条件禁止 | 无 |
| 访问凭据文件（如密钥、证书、环境变量文件） | 任何模式都禁止 | 无 |

**透明防护**：路径穿越会被拦截，系统敏感目录不可读写；凭据类文件禁止访问；工具输出超过上限会自动截断，单文件操作也有大小上限；上传的文件名会被消毒。这些都在后台默默生效，不需要你配置。

:::note 审批模式的取舍
自动审批适合你已经熟悉模型会做什么、盯着屏幕的场景；完全访问再往前一步，连高危确认也不弹——它只留下「模型缺条件时要问你一句」，适合你认可它大范围动手、但还得由你定方向；夜间模式适合你离开屏幕、让它自己跑完再看结果的场景——正因为它不会回头问你，任务描述里把目标与验收标准写清楚更重要，方向选偏了它会自己接着往下走。拿不准就用手动审批，多一两次点击，换来的是每一笔环境改动都经过你的许可。
:::
