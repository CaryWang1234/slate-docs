内置工具与技能

这一页是能力清单：SLATE 自带哪些工具、模型怎么用它们、哪些能关掉，以及怎么用 SKILL.md 和外部 MCP Server 把能力接得更多。

#两类能力先分清

  • 内置工具：SLATE 自带的 Python 能力，开箱即用，不需要配置也不用安装。文件读写、跑命令、生成文档、联网搜索都在这一类。
  • Skill：由 SKILL.md 定义的外部知识与流程。你自己写、上传或从本地路径导入，用来告诉模型"这件事该按什么步骤做"。

内置工具是"手"，Skill 是"做法"。两者都能被模型按需使用，也都能用 @ 显式点名。

#在哪管理：「扩展」页

顶栏「扩展」这一页是全部能力管理的入口，左栏七栏各管一类，数字与列表同源：

分栏管什么
技能SKILL.md 技能的导入、新建、删除，含「GitHub」与「发现插件」两个来源
工具自带工具清单（可查看，不可删除），关掉的功能连目录都不出现
模式回复模式的四档内置（只读）与自定义模式的建 / 改 / 删：追加提示词、工具白名单、推理强度与轮数上限
新功能工具工厂自己生产出来的工具：停用、看代码、查历史版本、回滚、撤销
MCP外部 MCP Server 的连接与它带来的远程工具
专家包角色设定 + 知识库 + 技能的组合，可新建与导入 zip
Actionsdata/actions/*.yml 流程说明书的编辑、校验、回滚

原先这些散在设置页的「工具 / 技能」与「MCP Server」两块，现已整块搬进这一页；设置页只留配置，不再兼做能力管理。

#重点工具

#file_edit：改动先给你看

  • 改动以 diff 形式呈现：文件名、+N -M 行数统计、红绿增删行，一屏看清动了什么。
  • 卡片上有「接受」「拒绝」「复制 diff」三个按钮：接受才落盘，拒绝只是关掉这张卡（这一笔不写入，但同一轮里已经写进去的内容不由这张卡回滚）。
  • 在「设置 → 上下文与项目」里勾选了「自动确认文件创建/修改」（默认勾选）时，预览没有报错的改动会直接写入，卡片显示「已自动应用」，不再给接受与拒绝。部分内容没命中时仍保留手动确认，避免只写进去半套。
  • 这一轮真正落盘的文件，会在模型说完最后一句话后汇总成一张「本轮改了哪些文件」卡片，可以在那里逐文件看 diff、整轮撤销，见 Agent Autopilot 与目标模式。
  • 编码安全：写入时保留原有的 UTF-8、BOM、GB18030、GBK、UTF-16 等编码，中文与 emoji 不会变成乱码。

#terminal：受限沙箱里跑命令

  • 单条命令超时 30 秒，输出超过 5 万字符会被截断，命令长度也有上限。
  • 支持多个终端会话并存，可以创建、列出、关闭，也可以终止会话里跑着的进程。
  • Windows 下每条命令一个独立 PowerShell 进程：多行块（foreach / if）与 && / || 都可用；cd 与 $env: 这类会话状态跨命令保持。
  • 交互式命令行（裸跑 python / node 这类等待输入的 REPL）拿不到输入就会退出或拖到超时，不适合在这里用。
  • 命令窗口不会弹到屏幕上，原生命令的输出捕获支持中文与 emoji。

#bg_task：后台终端任务的三层唤醒

编译、训练、起一个实验服务器这类以分钟计的活，交给它，不占住对话：

  1. 主动问：起完立刻返回任务标识、开头一小段输出与日志路径；之后用状态与日志查询去取新增输出。
  2. 结束时叫醒：起任务时带 notify=true，任务结束会把结果带着输出尾巴送回对话，模型被叫醒接着干。
  3. 提前叫醒：再挂一个正则，输出命中就提前唤醒，不必等命令跑完。

它是"起了就走"的一次性任务，不接受交互式输入；可以给超时让它到点自动终止，也可以随时停掉整棵进程树。任务寿命等于 SLATE 进程寿命——关掉 SLATE 任务就没了，日志留在本机可事后查。

后台不等于免审批

后台任务走的审批档位与终端完全一致，高危命令照样会弹窗问你，灾难级命令直接拒绝。

#搜索、Git 与联网

  • code_search：在项目里做全局代码搜索，支持文本与正则，默认从项目根开始，可以缩小到某个子目录。
  • git_tool：只读——看分支与工作区状态、最近提交、变更统计、分支与远程列表。它不会替你做提交、推送这类写操作，那些命令由模型在终端里执行，同样受审批约束。
  • web_search：免 Key 联网搜索，双引擎并发合并去重，取实时信息。
  • web_fetch：抓取指定网页的标题、描述与正文，支持需要 JS 渲染的页面与 PDF。

#工具怎么被调用

  • 模型自主调用：你直接描述需求（"把这份数据做成图表"），模型自己决定用哪个工具，不需要点名。
  • 对话里能看到：每笔调用都会变成一张工具卡，显示工具名、关键参数与执行状态，结果可展开查看。
  • 高危命令要审批：命令与联网访问都过审批门。审批档位有手动审批 / 自动审批 / 完全访问 / 夜间模式四档，本场可随时切换；完全访问把命令与联网的门关掉，但 AI 缺条件时照旧弹选择题问你一句；夜间模式再往前一步，全托管——命令、联网与模型的反问都不弹窗口。灾难级命令在任何档位下都无条件拦截。规则见 设置与安全审批。
  • 没做成会说实话：某项能力跑不动时（比如运行环境缺了依赖），工具卡显示的是失败，模型收到的也是一句失败说明——它会告诉你缺什么、需要你自己去装，不会把没生成的文件说成已经生成好了。安装依赖这件事由你在终端里做，模型不会代你去装东西。
  • 后台任务有独立面板：正在跑的后台终端任务列在右栏任务中心，可以直接查看与停止。

#工具的开关

「设置 → AI 辅助功能」是对话以外所有耗 Token 功能的开关。其中三项属于工具类：

  • 子代理并行（subagent_run）
  • AI 图片生成
  • AI 视频生成

关掉这三项中的任何一项，对应工具会从工具目录里消失——模型看不到它，也就不会调用它。图片与视频生成还需要在「图片生成」「视频生成」区块单独配置模型与 API Key。

#自定义 Skill

SKILL.md 即插即用。入口是顶栏「扩展」→「技能」栏，这一栏只放技能；内置工具在旁边的「工具」栏，只读不可删除。

一份 Skill 的写法：

  • 一个目录里放一个 SKILL.md，目录名就是技能名。
  • 文件里写清这份技能的用途（description: 一行）与要遵循的步骤、约定、注意事项。
  • 除了 SKILL.md，同一个目录里可以再放它需要的参考文档。

添加与删除：

  • 「新建技能」上传文件创建，「导入技能」从本地路径导入（给包含 SKILL.md 的目录，或单个 .md 文件）。
  • 「GitHub」从仓库导入，「发现插件」扫描本机已安装的 Codex / Claude 标准插件目录。
  • 技能可以删除，删除后模型与 @ 提及都不再看到它；内置工具不受影响。

#接入外部 MCP 服务器

在顶栏「扩展」→「MCP」栏里点「＋ 添加 MCP Server」，填名称与地址即可接入外部 MCP 工具。列表会显示连接状态、它提供的工具数量与工具名，并提供连接、断开、删除。

接入后，它的工具会出现在工具目录与 @ 提及候选里，模型可以像用内置工具一样调用。

项目级覆盖：打开一个项目后，列表里每台服务器会多出一个项目按钮，可以「在本项目停用」「在本项目单独启用」「摘掉本项目掩码」，也可以只放行其中几个工具。这类覆盖只影响当前项目，别的项目照旧；服务器的地址与密钥始终留在全局配置里，不会写进你的项目目录。详见 项目、工作区与分项目配置。

在输入框里点名

想明确指定用哪个工具或技能，直接在输入框输入 @ 从候选里挑，发送时会把它的定义注入这一条消息。@ 的候选范围与用法见 对话与消息。

#自进化工具（工具工厂）

mcp_factory 让 SLATE 把自己缺的工具写出来给自己用。产物一律落在用户数据区 data/evolved/，一个工具两份文件：<name>.py 是生成的代码，<name>.json 是说明与参数清单。

  • 为什么不写进 backend/skills/：那是程序自己的源码树——一次升级就把攒下的自产工具整个冲掉，而且程序不该在运行时改自己。data/ 升级覆盖不到，重启后清单照读。
  • 旧产物会自动搬过来：历史版本写进源码目录的生成物，启动时复制进 data/evolved/（只复制，不删程序自己目录里的文件）。
  • 管理入口：顶栏「扩展」→「新功能」栏。每条都写明当前状态：正常 / 已停用 / 代码有问题（带语法错误行号）/ 与内置工具同名（已由内置接管）。
  • 停用是整条摘掉，从模型的工具体系里消失，不是「调用时再报错」；随时可以再启用。
  • 覆盖、撤销、回滚都先留底到 data/evolved/.history/（每个工具最多 5 版）。条目弹窗里的「历史版本」可查看任一版原文并回滚；回滚本身也是写，编译不过的旧版本不许盖回去。
  • 语法不过的生成代码根本不落盘：工厂只做编译自检，绝不替你执行一次；与内置工具同名的创建请求当场拒绝。
  • 同名冲突时内置优先：升级若带来了同名内置工具，那份自产代码会被顶掉并在栏里标出来——看得见、随时撤得掉，不必跟新版较劲。
这些工具是你自己长出来的

自产工具由模型编写，能力与副作用不随内置工具的审计走。用之前可以在「新功能」栏里点开看代码；不放心就停用，或者撤销——留底还在，随时回滚。
