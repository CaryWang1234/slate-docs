数据、备份与存储

这一页解决三个问题：你的数据存在哪里、怎么备份与恢复、存储变大了该动哪一项。SLATE 是本地优先的工具，对话、记忆与设置都留在你自己这台机器上，API Key 也只在调用模型时使用。

#你的数据都在自己机器上

数据分两层：一层在数据库里，一层在数据目录的文件与文件夹里。你只需要记住「本机数据目录」这个粒度，删除或拷贝时整个目录一起处理。

存的是什么存在哪一层说明
会话与消息本机数据目录 · 数据库标题、消息正文、所用模型、Token 用量
长期记忆与用户画像本机数据目录 · 数据库自动沉淀的记忆条目，跨会话召回
提示词素材本机数据目录 · 数据库提示词工厂沉淀下来的片段
知识库文档本机数据目录 · 数据库知识片段与「灵光」归档
流程说明书 / 专家包 / 自定义技能本机数据目录 · 文件与文件夹流程说明书是单个文件，专家包与技能各自一个目录
偏好设置本机数据目录 · 配置文件主题、模型与密钥、审批模式、各项开关
备份文件本机数据目录 · 备份文件夹每次「下载备份」都会再留一份在本机
想整体搬走

本机数据目录就是你的全部家当。要么用「下载备份」导出一份 JSON，要么直接把整个数据目录拷到新机器上。

#历史会话管理

侧栏「任务」列表里，每一条会话都带着自己的信息与操作：

  • 搜索框：输入即过滤标题；输入 2 个字符以上还会做内容全文检索，命中后以「内容命中 · N 条」列出会话标题与上下文摘录，点一下直接跳到那场会话。
  • 悬停按钮：鼠标移到会话上，右侧出现三个按钮——重命名、导出 Markdown（按钮上标着 MD）、删除（×）。导出会生成一份包含全部问答的 Markdown 文件，文件名带会话标题与日期。
  • 归档：会话行的操作里有一颗「归档」，按下去这一场就从「任务」栏离场，消息一条不动。正在生成的那场不能归档（先停下来再收）。归档的会话在「设置 → 会话归档」里逐条恢复或删除——恢复后它重新出现在任务栏，删除会连同消息一起清掉、找不回来。
  • 排序下拉：在侧栏头部，可切换最近更新 / 按项目 / 按状态 / 创建时间 / 按用量。
  • 管理：侧栏头部的「管理」按钮打开「管理历史会话」弹窗，逐条勾选后可「删除选中」，也可以直接「清空全部」；顶部「全部」勾选框一次选中当前所有会话。

删除会话、删除消息、清空全部都无法撤销。删除前建议先在「数据备份」里导出一份。

#消息级操作

在消息区，每条消息右上角都有一排小按钮：

按钮作用适用范围
复制复制这条消息的正文所有消息
编辑内容就地改成输入框，保存后写回并重新渲染用户消息
删除此消息从这场会话里移除这一条用户消息
重新生成以这条之前的历史重新请求一次回答最后一条助手消息

编辑或删除消息只影响这一条，不会动到其他会话。想了解对话本身的用法，见 对话与消息。

#一键备份与恢复

一次导出，把「对话、记忆、素材与设置」全部收进一个 JSON 文件。

备份包含什么

  • 全部会话与消息、长期记忆、提示词素材，以及用量记录。
  • 本机偏好设置：模型与 API Key、自定义模型、主题、审批模式、AI 辅助功能开关等。
  • 所以备份文件里含你的 API Key，不要随手发给别人。

什么时候该备份

  • 卸载、重装或换电脑之前。
  • 准备执行「清空对话」这类不可逆操作之前。
  • 在做大批量整理、删除会话之前。

导入会发生什么

  • 会话、消息、记忆与素材按 ID 合并：已存在的数据会跳过，不会覆盖你现有的内容。
  • 本机偏好会被备份里那一份替换，导入完成后页面会自动重载以应用设置。
  • 导入前会弹一次确认，确认后才会开始。
导入前先确认

备份是「合并进当前数据」，不是「清空再恢复」。你当前这台机器上的偏好设置会被备份里的那份覆盖；如果两边都存了你想保留的模型密钥，导入后可能不符合预期。拿不准就先导出一份当前的备份，再导入旧的。

#存储空间管理

在「设置 → 数据备份」区域下方是「存储空间」，先显示总占用，再按分项列出各自的大小。

分项里面是什么可以做什么什么时候该用
对话历史数据库会话与消息、长期记忆、提示词素材、用量压缩、清空对话删掉很多会话后想回收空间；或历史太杂想从头开始
内置浏览器缓存内置浏览器运行产生的缓存文件清理缓存页面显示异常，或这一项明显变大
自定义技能你导入或新建的技能文档不可清理建议保留
配置文件主题、模型与密钥、各项开关不可清理建议保留
其他知识库、日志、流程说明书、专家包等不可清理建议保留

三个操作的区别：

  • 压缩：把数据库里已删除数据占用的空间真正还给磁盘，不动任何现有内容。适合「刚删了很多会话」之后。
  • 清空对话：删除全部会话与消息，长期记忆、知识库与偏好设置不受影响。不可恢复，操作前会有一次确认。
  • 清理缓存：清掉内置浏览器的缓存文件。运行中被占用的文件会在下次启动后彻底释放。

#跨设备同步与本机偏好

如果你用手机遥控同一个 SLATE，一部分偏好会跟着你走，另一部分刻意只留在这台机器上。

偏好是否跨设备
侧栏任务列表排序跨设备同步
主题与明暗、通用 UI 模式跨设备同步
模型与 API Key、自定义模型、当前模型跨设备同步
审批模式、推理强度、AI 辅助功能开关跨设备同步
通知开关、联网搜索、图片与视频生成配置跨设备同步
阅读进度与未读标志（需要操作 / 出错 / 进行中 / 已完成未查看）只留本机
任务清单栏的折叠状态只留本机
Continue Autopilot 与多任务并行相关开关只留本机

阅读进度只在本机，是因为「我有没有看过这一场」是这台设备的感受：在另一台设备上看过，不应该让这边也变成已读。

#卸载或换电脑：迁移三步

  1. 在旧机器上打开「设置 → 数据备份」，点「下载备份」，确认拿到 SLATE-backup-日期.json。
  2. 在新机器上装好 SLATE 并启动，进入「设置 → 数据备份」。
  3. 点「导入备份」，选择刚才那个 JSON，确认后等待页面自动重载。

迁移后如发现知识库文档、流程说明书、专家包或自定义技能没有跟过来，可以把旧机器上的本机数据目录整个拷到新机器对应位置——它们不在那份 JSON 里，而是以文件与文件夹的形式保存。模型与 API Key 若未随备份导入，在新机器的模型配置里重新填一次即可。

别把备份当同步盘

备份是某一时刻的快照。反复在同一份旧备份上叠加导入，并不会合并出「最新状态」，还会让新旧记录混杂。要持续同步，直接用局域网遥控访问同一台机器，见 移动端遥控与局域网访问。
