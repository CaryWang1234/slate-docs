常见问题

这一页收集使用中最常遇到的疑问，按「先看哪一页」的方式给出答案。每条都能点进对应的页面看完整说明。

#按症状速查

报 Bug 前先确认一件事

不少「没反应」其实不是故障：可能是审批弹窗正等你点批准，也可能是这一场在排队（排队中的任务在右栏任务中心与输入框上方都看得见）。先扫一眼屏幕上有没有待处理的提示，再判断是不是真卡住了。

#模型连不上，或提示 API Key 无效怎么办

先到「设置 → 模型配置」确认这个模型已经填好 API Key。不确定是密钥问题还是网络问题时，用「设置 → API 测试」跑一条最短请求，它会走真实对话同一条链路并给出结果。自定义端点要注意 Base URL 与请求模式是否匹配（OpenAI 兼容 / Anthropic / curl 直连）。本地模型则要确认 Ollama 或 LM Studio 已经在运行。详见 模型接入与 API Key。

#为什么模型不调用工具，只是嘴上说要做什么

先检查「设置 → 自动推进」是否被关掉了——它专门负责在模型只表态不动手时催它补上工具调用。再确认「Continue Autopilot」是否开启，它会让轮数用尽的最后一刻继续推进。另外看看是不是有审批弹窗正等你点「批准」，没批准模型是不会往下走的。完整机制见 Agent Autopilot 与目标模式。

#终端命令被拦下来了

命中写死的高危规则时（删除文件、提权、关机重启、强制推送等）会弹窗让你确认，批准前还能看到一句由模型生成的命令目的说明。灾难级命令在任何模式下都无条件禁止，这是设计如此。如果同类命令频繁被问，可把这一场或默认档位切到自动审批，只拦高危。见 设置与安全审批。

#中文或 emoji 出现乱码

文件读取与编辑会自动识别 UTF-8、UTF-8 BOM、GB18030、GBK、UTF-16 等常见编码，中文、emoji 与全角符号会原样保留；旧编码表达不了新字符时，工具会安全升级写入编码而不是丢字。终端输出对原生命令做了编码安全处理，Windows 下也不会再弹出黑窗乱码。若仍然遇到乱码：先确认文件不是被外部程序以别的编码改写过，再用文件读取工具重新查看一次；必要时让内容以 UTF-8 重新保存。

#局域网或手机连不上 SLATE

按顺序排查四件事：手机与电脑是否在同一个 Wi-Fi；电脑防火墙是否拦了端口（首次开启时要点允许）；地址是否用的是设置页显示的那一条（必须带授权码）；路由器是否开启了访客网络或 AP 隔离。若设置页提示「遥控服务未启动」，重启应用即可。见 移动端遥控与局域网访问。

#数据太多了怎么清理

到「设置 → 数据备份 → 存储空间」先看总占用与分项。删掉一批会话后可以点「压缩」把空间真正还回来；想彻底重来可以「清空对话」，它只删会话与消息，不动长期记忆与偏好。内置浏览器缓存变大时点「清理缓存」。清理前建议先导出一份备份，详见 数据、备份与存储。

#怎么省 Token，或者关掉用不到的 AI 功能

到「设置 → AI 辅助功能」，那里列着对话以外的 15 项耗 Token 功能，逐项可关，关掉后一次请求都不会为它发出。日常只做对话与工具执行的话，压缩摘要、记忆蒸馏、对话洞察、自动会话标题、提示词优化、图片与视频生成这些可以先关。列表上方会实时汇总已经关掉了几项。见 设置与安全审批。

#会话太多，又不舍得删怎么办

「任务」栏每一行的操作里有一颗「归档」：按下去这场就从任务栏离场，但消息一条不动——归档不是删除。正在生成的那场不能归档，先停下来再收。要拿回来去「设置 → 会话归档」，逐条「恢复」它就重新出现在任务栏；那里的「删除」才是连消息一起清掉、找不回来的那一个。见 数据、备份与存储。

#工具列表里少了几个工具

先看「设置 → AI 辅助功能」里对应功能的开关：子代理、图片生成、视频生成这三项关掉后，工具会直接从工具目录消失，模型看不到也就不会调用。图片与视频生成还需要在「图片生成 / 视频生成」区块里配好模型与 API Key，没配好同样不可用。若挂了外部 MCP Server，连接断开时它提供的工具也会暂时不在。见 内置工具与技能。

#自定义流程说明书校验不过

流程说明书用的是极简格式：2 空格缩进、块数组、竖线字面量块。Tab 缩进、锚点、多文档等写法一律会被拒收，报错会写明「第 N 行：原因」，按住这个行号改就能过。校验没过是保存不了的，编辑器会边写边校验。完整字段与写法见 Actions 流程说明书。

#辩论中途想停怎么办

团队面板上有停止按钮，点一下即中断后续发言，已经说完的内容会完整保留，不会丢成果。这一场也会进团队历史并标「已中断」，点开还能接着看——没有结论的场次不会被编出一份结论。停完之后你还可以接着追问，或换一组角色重新开一场。见 AI 团队与工作流。

#切换项目会不会打断正在跑的对话

默认不会。离开的那一场会在后台继续生成，进度与结局落在右栏任务中心；同一项目内默认串行，跨项目可以并行，同时最多跑几场可以在「设置 → 多任务与项目」里调。如果你希望恢复「切换即中断」的旧行为，把该区块里的开关关掉即可。见 项目、工作区与分项目配置。

#移动端怎么设访问密码

SLATE 的局域网访问不是用「设一串密码」的方式保护的，而是靠地址里自带的授权码：只有用设置页给出的那条地址或它的二维码进入的设备才能访问，不带授权码的访问会被自动拦下。因此保护办法是——不要把带授权码的地址或二维码发给别人，发出去等于把钥匙交出去。不需要遥控时关掉电脑上的 SLATE 即可让地址失效。见 移动端遥控与局域网访问。

#怎么换界面语言

界面语言在安装时选定（简体中文或 English），应用运行中不提供切换入口，所以想换语言需要重新运行安装程序并选择另一种语言。切换语言只影响界面文案，模型生成的内容与你的输入不会被翻译。相关说明见 设置与安全审批。

#换电脑或重装后怎么迁移数据

三步：在旧机器上「设置 → 数据备份 → 下载备份」拿到一个 JSON；在新机器上「设置 → 数据备份」点「导入备份」选中它；确认后页面自动重载。导入是按 ID 合并，已存在的数据会跳过，但本机偏好会被备份里那份替换。知识库文档、流程说明书、专家包与自定义技能不在这个 JSON 里，需要把本机数据目录一并带过去。见 数据、备份与存储。

#生成的提示词怎么用在 Claude Code、Codex 或 Cursor 里

提示词工厂产出的是可交付的纯文本 Prompt，把它整段复制，粘贴到外部 Coding Agent 的对话框或项目说明文件里即可，格式不需要再改。想让它更贴合某个工具的习惯，可以在工厂里把交付要求与约束写清楚再生成。见 提示词工厂。

#我能用它做什么，不适合做什么

它适合把灵感整理成结构化方案、驱动本机工具干活、把重复流程写成说明书反复使用，也适合生成高质量 Prompt 交给外部 Coding Agent 执行。不适合当纯粹的云端助手、不适合多人在线协作，也不适合在不受信任的公共网络里开放局域网遥控。见 认识 SLATE。

#任务列表上那些小标志是什么意思

每条会话会按当下处境给一个标志：需要操作（上一场被停止或还有下一步）、出错、进行中（带呼吸动画，只在这一场真的在生成时出现）、已完成未查看（点进去即清除）。标志记的是「上一场怎么结束的」，如果这场会话在手机遥控那边被继续过，旧标志会自动作废。见 界面总览：三栏工作台。

#对话很长了会不会超出模型窗口

不会直接超。上下文预算用满时会自动把旧消息压成一段摘要，压缩阈值与用量条分母都按你给这个模型设的预算算。想手动压一次，就在对话里点「压缩」。预算在「设置 → 上下文与项目」与模型行上的「最大上下文」里调，本地端点还能一键探测它的真实窗口，见 设置与安全审批。

#磨墨模式产出的墨稿接下来怎么用

墨稿有三键：送入目标模式执行、投到白板推演、存为模板复用。想先看看再决定，就投到白板；想直接开干，就送进目标模式。见 磨墨模式。

#长期记忆会不会记错

会，所以它可改可删。在记忆面板里逐条编辑内容或直接删除，过时信息被修正后，后续对话召回的就是新内容。开启记忆自动蒸馏时，每轮回复后都会静默读一遍最近对话，45 秒内不重复。见 记忆、画像与知识库。

#白板上的卡片是谁建的

两种来源：模型在干活时自动建的（工具执行会记成带状态颜色的步骤卡片），以及你手动拖拽新建的。卡片、连线与步骤卡都能自己编辑和清理。见 白板式逻辑链。

#定时任务到点了却没执行

先确认任务处于启用状态，再检查「设置 → AI 辅助功能」里的「定时与事件任务」是否被关掉了——关掉后任务不再执行，但触发记录仍会保留。结果会归档到带前缀的独立会话里，去会话列表找那一场即可。见 任务清单与定时任务。

#想给一段重复流程写个说明书，该从哪下手

把它写成 Actions 流程说明书，模型在智能体态下会自动看到目录，按需读取全文再照流程推进。写坏的版本不会凭空消失，会连同原因一起列出来，每次覆盖或删除都会留底、可一键回滚。见 Actions 流程说明书。

#我能让 SLATE 直接用我自己的技能吗

可以。把技能写成一份 SKILL.md 就能被识别，之后在聊天里用 @ 提及，它就会被注入这条消息的上下文。专家包则是「人格 + 规则 + 知识 + 技能」的整套，可导入可导出。见 内置工具与技能 与 专家包。
