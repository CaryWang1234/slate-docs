移动端遥控与局域网访问

这一页解决「人离开电脑，但活还没干完」的问题：手机或平板连上同一个局域网，就能用浏览器遥控桌面上的 SLATE，界面会自动切换成专门的移动端样子。SLATE 启动时就已经把局域网访问开好了，不需要额外配置。

#能干什么

  • 查看正在跑的对话与工具调用进度，接着聊下去。
  • 新建会话、切换会话、重命名与删除。
  • 增删改长期记忆，查看与管理待办（定时任务）。
  • 切换模型、填 API Key、切换深色模式。
  • 高危命令与文件改动会弹底部面板让你确认，和桌面是同一套判断规则。

#怎么连上

  1. 让手机与电脑连在同一个局域网（同一个 Wi-Fi）。
  2. 在电脑上打开「设置 → 局域网遥控」，会看到一条访问地址与一个二维码。
  3. 手机扫码，或把地址复制到手机浏览器打开，即可进入专属移动端界面。

地址里的端口默认是 8001；这个端口被占用时 SLATE 会自动向后找一个可用端口，所以以设置页显示的地址为准。顶栏的「遥控」按钮也能直接跳到这一块设置。

#为什么桌面界面没变

移动端界面是独立入口，只有手机与平板这一类设备访问局域网地址时才会进入。你在电脑浏览器里看到的仍然是完整的三栏桌面工作台，功能、布局、快捷键都不受影响，属于零回归。

想在手机上强制看桌面界面

在地址后面加上 slate_mobile=0 再打开，就会停留在桌面界面。平板上屏幕够大、又想用完整布局时可以这样进。

#五个底部 Tab

Tab主要用途具体能做什么
对话接着干活看流式输出、思考折叠卡与工具卡片，继续追问或停止本轮
会话找历史会话列表，新建、切换、重命名、删除
记忆管长期记忆增删改查，新建时选择分类
待办管定时任务查看下次触发、启用停用、立即运行、删除、新建
设置调整本机偏好模型切换、推理强度、密钥、外观、遥控信息

对话：输入框固定在底部，回车发送、Shift + Enter 换行，输入 @ 弹出提及候选。消息按气泡呈现，模型的思考过程收在可折叠卡片里，工具调用显示成带状态的工具卡；生成过程中上翻不会被自动滚动打断。

会话：与桌面共用同一份后端数据，手机上改过的标题、新建的会话，回到电脑刷新就能看到；反过来也一样。在手机上继续过的那场会话，桌面上旧的「已完成未查看」之类标志会自动作废，不会留下过时的结论。

记忆：一条条列出长期记忆，点进去可编辑内容或改分类，也可以直接删除；新建记忆时填内容并选一个分类，之后在对话里会被自动召回。

待办：每个定时任务是一行，可查看它的时间或间隔、临时启用或停用、点「立即运行」立刻执行一次，以及删除。新建时依次填名称、提示词、模型、模式与时间或间隔。

设置：一屏之内改完手机上最需要的几件事，改完立即生效。

#遥控时的分工

移动端是「遥控器」，不是第二份数据：

  • 数据仍是同一份：会话、记忆、待办都存在桌面那台机器的本机数据目录里，手机只是操作它。
  • 任务仍在电脑上跑：模型请求与工具执行发生在电脑端，手机只是发起与查看。所以关掉电脑上的 SLATE，遥控就结束了。
  • 运行时请不要让电脑休眠：休眠会中断正在跑的生成与后台任务。
  • 桌面上的窗口不需要保持在前台，但应用要处于运行状态。

#什么时候用遥控、什么时候回到电脑前

场景建议
长任务跑到一半要出门用遥控看进度，必要时补一句指令
只想改个标题、删个会话、看看记忆遥控足够
批量整理历史、往模板里塞大段上下文回桌面，屏幕大、操作快
管理技能、编辑流程说明书、配置 MCP Server回桌面，这些区块只在桌面设置页
多人协作、把界面投给别人看不建议，遥控地址等于钥匙

#移动端对话的能力

  • 流式输出：逐字出现，和桌面同一套协议；上翻时不会被自动滚动打断，贴底时自动跟随。
  • 工具循环：与桌面共用同一条 Agent 循环逻辑，模型能观察、执行、验证、汇报；界面同源，工具卡的标题不会退化成裸英文工具名。
  • 高危命令确认：命中写死的高危规则时，弹出底部面板，写明命令与触发规则，并附一句由模型生成的命令目的说明，由你决定批准还是拒绝。
  • 文件变更确认：文件编辑与新建会先给你看差异，选择接受才落盘，拒绝则不写入。
  • @ 提及：输入 @ 弹出候选浮层，可提及技能、工具与项目文件，支持上下键选择、Tab 或点击插入。
  • 停止真取消：点停止会连同工具调用的流式通道一起关闭，后端终止对应的子进程与在跑任务。

#移动端设置能改什么

设置项说明
模型选择按国产 / 国际 / 本地 / 自定义分组列出，点一下即切换，并显示每个模型的上下文预算
推理强度档位随当前模型能力给出（自动 / 关 / 低 / 中 / 高），与桌面输入框那个选择器是同一份状态
密钥为当前模型填入或清除 API Key
外观深色模式开关；顶部状态条还有一个快捷的主题切换按钮。电脑上开了自定义主题时，这一项会写明「已锁定」，点切换只会说明原因，不会换色
遥控信息显示带授权的访问地址与二维码，可一键复制

#鉴权与风险

局域网访问靠地址里自带的授权码放行：只有通过设置页给出的那条地址（或它的二维码）进入的设备才能访问，地址里没有授权码的访问会被拦在一张「需要授权」的页面上。授权码保存在设备上，之后再用同一浏览器访问不必重复扫码。

别把访问地址发出去

这条带授权码的地址就是钥匙。任何拿到它的设备，只要连进同一个局域网，就能打开并操作你的 SLATE——读文件、跑命令、看全部历史会话。不要在群里、论坛或截图里暴露这条地址。不再需要遥控时，关掉电脑端的 SLATE 即可让地址失效。

安全建议：这是把本机服务开放到局域网，建议只在你自己能信任的网络里使用。在咖啡厅、酒店、机场这类公共 Wi-Fi 下，关闭 SLATE 或不要使用遥控功能。

#连不上怎么排查

  1. 手机和电脑是否在同一个 Wi-Fi：手机用的是蜂窝数据、或连了另一个频段的访客网络，都不算同一个局域网。
  2. 电脑防火墙是否拦了端口：第一次开放局域网访问时，系统可能弹出防火墙询问，需要选择允许；若当时点了拒绝，去防火墙设置里为 SLATE 放行。
  3. 地址是否用了电脑的局域网 IP：要用设置页显示的那条地址，而不是本机回环地址。
  4. 是否被访客网络隔离：不少路由器默认开启「AP 隔离」，同一 Wi-Fi 下设备之间也互相看不见，需要在路由器设置里关掉，或换成手机热点。

按现象对照排查会更快：

现象最可能的原因怎么办
页面一直转圈打不开电脑不在运行，或端口被防火墙拦了确认电脑上 SLATE 在运行；为它放行防火墙
打开后停在「需要授权」页地址漏了授权码回到设置页复制完整地址，或重新扫码
平板打开后是桌面界面平板被判为桌面设备属预期行为，功能不受影响；想用移动端界面请用手机浏览器打开同一条地址
昨天能连，今天不行电脑换了网络，IP 变了重新打开设置页，用新显示的地址
只有一台手机连不上访客网络隔离或系统限流检查路由器 AP 隔离，或换手机热点试一次

其他还要看的：设置页若提示「遥控服务未启动」，重启应用即可；地址里的端口被别的程序占用时 SLATE 会自动换一个，所以始终以设置页当下显示的地址为准。

地址会变吗

电脑换了 Wi-Fi、路由器重新分配了地址，访问链接就会跟着变；端口被占用时也会换。所以换网络之后别用旧地址，回到设置页重新看一眼再扫码。
