对话与消息

这一页讲你在对话框里最常用到的操作：怎么开一场对话、怎么把消息发出去、怎么把文件与技能塞进这一条消息，以及 Token 都花在了哪里。

#开一场对话

  • 侧栏「任务」页签顶部点「＋ 新建对话」，或按 Ctrl + N。
  • 点侧栏里任意一条会话即切换过去，当前会话的完整历史重新铺开。
  • 排序下拉可切换：最近更新 / 按项目 / 按状态 / 创建时间 / 按用量。排序偏好跨设备同步。
  • 每条会话带一个状态标志：需要操作（上一场还有下一步或被停过）、出错、进行中（呼吸动画）、已完成未查看。点进会话即视为看过。

发送时 Enter 发送，Shift + Enter 换行。

标志记的是"上一场怎么结束的"：如果你后来在手机端或另一条会话里继续过它，旧标志会自动作废。

#消息基本操作

  • 流式输出：回复逐字落下，不必等整段结束就能开始读。
  • 停止：生成期间发送按钮变成「停止」。点它是真取消——模型流与工具调用的流式通道一起关闭，后端也随之终止正在跑的子进程与任务，不会出现"界面停了、活还在干"。
  • 重新生成：每条助手回复下方都有「重新生成」。它会以这条回复之前的历史重新请求，并重写这条回复之后的内容。
  • 代码块一键复制：代码块右上角有「复制」按钮。
  • 智能滚动跟随：滚动条在底部时输出自动跟着走；你往上翻看历史时不会被强行拉回底部。

#编辑与删除消息

鼠标移到消息上会浮出操作按钮：

  • 「复制」把这条消息的内容放进剪贴板。
  • 「重新生成」只出现在助手消息上。
  • 「编辑内容」让正文就地变成输入框，保存后写回这条消息。
  • 「删除此消息」会先问一次，删除后不可恢复。

#四种输入方式对比

输入方式怎么用适合什么
文字直接打字，Enter 发送绝大多数需求
语音点输入框右侧的麦克风按钮口述不想打字、边说边理思路
优化提示词点语音按钮左边的星形按钮，让模型把草稿改写一遍需求写得含糊，想让措辞更明确
附件点回形针按钮选择文件让 AI 读一份现成的文件
@ 提及输入 @ 选候选，或从 ＋ 菜单进入对应分组明确指定用哪个工具、技能或哪份文件

#附件与多模态输入

点输入框左侧的回形针按钮添加附件，单个文件最大 10MB。

  • 文本类（.md / .html / .css / .js / .py / .json / .yaml / .log 等）：直接读取正文。
  • 表格类（.csv / .tsv）：解析成结构化数据，而不是一整块文本。
  • 图片（.png / .jpg / .jpeg / .gif / .webp / .bmp / .svg）：转成多模态输入交给模型看。
  • 文档类（.docx / .xlsx / .pdf）：由 SLATE 自己解析出段落、表格与正文后再送入对话。
附件是先解析再送

SLATE 在本地把文件解析成正文或结构化数据，而不是把整份原始文件塞进上下文。这一步在本地完成，不额外多花 Token。

#语音输入

输入框右侧的麦克风按钮点一下开始口述，再点一下停止。

  • 基于浏览器语音识别，边说边实时转写，转写结果直接落进输入框，不会打断你已有的草稿。
  • 识别语言跟随界面语言：中文界面按中文识别，English 界面按英文识别。
  • 需要浏览器与系统支持，Chrome / Edge 可用；首次使用需授权麦克风。
看不到麦克风按钮

按钮只在当前浏览器支持语音识别时才显示。如果它没出现，说明这套环境不支持，请改用打字输入。

#优化提示词

麦克风按钮左边那颗星形按钮，把输入框里已经写好的草稿交给模型改写一遍。它改的是你这条还没发的话，不是让模型替你回答。

流程是：点一下 → 模型改写 → 弹窗里左右并排看原文与改写 → 自己决定。

  • 点采用才写回输入框，然后你照常按 Enter 发送。
  • 点保留原文、按 Esc、点弹窗外面，都算不采用，输入框一个字都不会变。
  • 等结果的那几秒输入框还能继续打字。如果你（或语音听写）改了草稿，这次改写结果会被放弃，不会盖掉你新写的内容。
  • 模型用代码块包住结果时，取的是里面的正文，回填进来的不会有那对反引号围栏。
  • 用哪个模型在这里单独指定：设置 → AI 辅助功能 → 提示词优化。关掉它，点按钮只会提示一句已关闭，一次请求都不发。
它不改你的意思

提示词里写给模型的要求是"保持原意、不要新增你没提到的目标与细节"，并且要求 @ 提及、代码、路径、数字原样保留。改写只是把话说清楚，不是把需求换掉。

#@ 提及

在输入框输入 @ 会弹出候选；也可以点输入框左侧的 ＋ 菜单，在「提及（@ 前缀）」分组里直接打开某一类：

  • 技能：把 SKILL.md 定义的流程注入这一条消息。
  • 工具：指定使用哪个内置工具。
  • MCP：使用外部 MCP Server 提供的工具。
  • 文件：把项目文件的正文（或目录结构）注入这条消息，打开项目后才可用。

候选里还会出现流程说明书与专家包：@ 一个流程 id 会注入整份流程，@ 一个专家包名会注入它的人格、规则与知识文件。

完整的工具与技能清单见 内置工具与技能。

#上下文与用量

对话区顶部有一条用量信息栏，鼠标悬停可以看到上下文被谁占走了：

分桶装的是什么
系统提示词角色设定、项目宪法等固定内容
工具目录这一场对话里模型能看到哪些工具
Skill 注入被 @ 提及带进来的技能与文件内容
工具调用与结果模型调了什么、工具回了什么
对话消息你和模型真正说过的话
  • 上下文条的分母是你为该模型设定的上下文预算，不是模型标称的窗口大小，所以它更像"距离压缩还有多远"的预告。
  • 占用超过阈值时，SLATE 会自动把较早的对话压成一段历史摘要，最近几轮保持原样。
  • 系统发给模型的催办与工具结果投喂（见 Agent Autopilot 与目标模式）只出现在模型那一侧，不占消息区；压缩之后它们仍在上下文里继续生效，也不会突然变成一条气泡。
  • 摘要发给模型时仍是完整原文，只在消息区折成一条折叠条：点标题才展开，长历史不会把最近几轮挤出屏幕。
  • 也可以手动压缩：点工具栏的压缩按钮，选轻度或重度两档后开始。
档位保留什么
轻度压缩保留关键细节与可能被引用的文件名、数值等事实，约 50% 压缩
重度压缩只留核心结论、关键决策与明确待办，约 80% 压缩
什么时候该手动压缩

自动压缩只在超出阈值时发生。如果这一场的前半段夹着大量"读文件、试错、来回确认"的中间过程，而你接下来要谈的是另一件事，提前手动压一次比等它自动触发更划算：轻度档能保住文件名与数值，重度档只留结论、细节会丢。

#记忆与画像的自动注入

长期记忆与用户画像由 SLATE 在后台挑选相关条目注入对话，不需要你手动粘贴。查看、增删与从当前对话提取记忆，见 记忆、画像与知识库。

#历史会话

侧栏「任务」页签上方有「搜索历史会话」，输入关键词即全文搜索，命中会显示上下文摘录，点一下直达那条会话。新建的会话先拿首条消息的前 30 字当占位标题，跑完首轮由模型补一个短名字——只替换这种占位标题，你自己改过的名字不动（这一项可以在「设置 → AI 辅助功能」里关掉）。右侧「管理」按钮进入批量管理，可重命名、导出为 Markdown、批量删除。每一行的操作里还有一颗「归档」：它只让这一场从任务栏离场，消息一条不动，要拿回来去「设置 → 会话归档」。数据备份与导出细节见 数据、备份与存储。

#定时任务产出的会话

定时与事件任务执行完会自动落成一条独立会话，标题带 [定时] 或 [事件] 前缀，方便你在侧栏里直接认出它们。任务怎么创建见 任务清单与定时任务。

需要 AI 自己动手改文件、跑命令时，可以看 Agent Autopilot 与目标模式 与 磨墨模式。
