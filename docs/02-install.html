安装与启动

这页带你装好 SLATE 并跑起来，同时说明首次启动会发生什么、你的数据放在哪里。

#系统要求

项目要求
Windows 桌面版直接使用安装包，无需额外准备运行环境
macOS 桌面版直接使用 .dmg，无需额外准备运行环境
源码运行Python 3.13 或更高版本
源码运行平台Windows / Linux / macOS 都可以
网络首次启动后需要联网调用你配置的模型
浏览器使用源码方式时，用较新版本的 Chrome / Edge / Firefox 打开本机地址

#方式一：Windows 安装包

适合大多数使用者，装完即用，不需要装 Python。

  1. 前往项目的 GitHub Releases 页面，下载最新版安装包 SLATE-Setup-x.x.x.exe。
  2. 双击运行安装程序。
  3. 安装过程中选择界面语言：简体中文 或 English。
  4. 安装完成后从开始菜单或桌面快捷方式启动。
界面语言在安装时选定

语言在安装那一步就定下来了，之后界面与提示文字全程使用该语言。想换语言，重新运行一次安装程序选择即可。

再双击一次不会多开一个窗口

同一份安装只会跑一个 SLATE。窗口已经开着（或已经缩进系统通知区域）时再启动一次，不会多出一个窗口、也不会多起一份后端：新启动的那个会把正在跑的窗口唤回前台，然后自己退掉。锁随进程消失，崩溃或被任务管理器结束都不会留下"再也打不开"的状态。

#方式二：macOS 安装包

苹果电脑用 .dmg，装完即用，同样不需要装 Python。

  1. 前往项目的 GitHub Releases 页面，下载最新版 SLATE-Setup-x.x.x.dmg（同目录有 SLATE-Setup-x.x.x.dmg.sha256，想核对一下再装可以用 shasum -a 256 -c）。
  2. 双击挂载，把「SLATE 砚」拖进「应用程序」文件夹。
  3. 首次启动：在访达里右键（或长按）SLATE 图标 → 「打开」 → 再点一次「打开」。
  4. 此后就能正常双击启动。
这个包还没有代码签名与公证

.dmg 由 CI 直接产出，没有 Apple 开发者证书签名，也没有做公证，所以第一次打开会被 Gatekeeper 拦一句"无法验证开发者"。上面第 3 步的右键 → 打开就是绕过它的正规做法，只需要做一次。想校验下载是否完整，比对同名的 .sha256 文件即可。

Mac 上的数据在哪个目录

装机版把对话历史、API Key、后端日志和 WebView 的个人资料都放在 ~/Library/Application Support/SLATE，不在 .app 包里。升级就是整个替换 .app，你的数据不会被一起带走。源码运行仍然把数据放在仓库的 data/。

托盘与单实例暂时只有 Windows 有

Mac 上关掉窗口就是退出应用；连续启动两次会开出两份。这两条后续再补。

#方式三：从源码运行

适合想自己改点东西、或使用 Linux 的人（macOS 也能这样跑，只是没必要——有现成的 .dmg）。

bash
git clone https://github.com/CaryWang1234/SLATE.git
cd SLATE
pip install -r requirements.txt

Windows：

bash
start.bat

Linux / macOS：

bash
chmod +x start.sh
./start.sh

启动完成后，在浏览器里打开：

text
http://127.0.0.1:8000

也可以直接运行桌面入口 python desktop.py，以桌面窗口的方式打开同一个应用。

#首次启动会发生什么

  1. 主窗口打开后，会先弹出一份新手引导，用几张卡片带你认识多模型对话、目标模式、磨墨模式、内置工具、记忆与知识库、其他面板这几个入口。
  2. 点「开始使用」关闭引导，进入主界面。
  3. 主界面顶栏有五个页签：对话 / 黑板 / 扩展 / 工厂 / 设置，每次显示其中一块。默认停在「对话」，这一块内部再分左右两栏：左侧边栏放项目与任务，右侧是对话消息流与输入框，消息区右缘按需滑出任务清单与后台任务面板。技能、工具、模式、MCP、专家包、Actions 这些「模型能用什么」都收在「扩展」那一页。

新手引导只看一次。之后想重看，去 设置 → 关于，点里面的「新手引导」按钮。

#安装后第一件事

SLATE 装好时还没有任何模型可用，先去配置 API Key：

  1. 点顶栏右侧的密钥按钮，或直接切到设置页签。
  2. 在「模型配置」里找到你要用的模型，填入对应的 API Key 并保存。
  3. 想接入别家端点，点同一区块的「+ 添加模型」，填写模型 ID 与 API 地址。
  4. 回到对话界面，在输入区的模型下拉框里选中刚配置好的模型。

配置细节与各家模型清单见模型接入与 API Key。

首次启动需要联网

SLATE 本体跑在本机，但它要调用你配置的模型来完成对话与推理。所以第一次使用前，请确认这台电脑能访问你选择的服务端点，并且该 API Key 有可用额度。没有配好模型时，你能看到界面与历史记录，但发出去的消息不会得到回复。

不要把 API Key 写进会被公开的地方

API Key 保存在本机的应用配置里，不需要你另外记到笔记或项目文件里。请避免把它写进会提交到代码仓库、或会分享给别人的文档中；一旦泄漏，请立刻到服务商后台吊销并重新生成。

#启动时自动检查更新

SLATE 每次启动都会检查一次新版本：

  • 发现新版本时，顶栏下方会出现一条提示横幅，上面给出下载与查看发行说明的入口。
  • 横幅右上角可以关闭，选择「忽略该版本」后不再为这个版本反复提示。
  • 也可以随时手动检查：设置 → 关于，点「检查更新」，那里同时显示你当前的版本号。

安装包来源始终是项目的 GitHub Releases，SLATE 不会从别处下载可执行文件。

#卸载与你的数据

卸载：Windows 下用系统的「应用」列表卸载 SLATE 即可，卸载程序负责移除应用本体。

数据：对话历史、记忆、知识文档、专家包、动作流程与各项设置都以本机文件形式保存，不上传云端。所以：

  • 想换电脑，先做一次导出备份，在新机器上导入即可（见数据、备份与存储）。
  • 想彻底清理，也建议先导出一次备份确认无误，再动手删除。
  • 卸载应用与删除数据是两件事，请按你的需要分别处理。

#启动不上怎么办

  • 双击图标后什么都没出现：多半已经有一个 SLATE 在跑（窗口可能正缩在系统通知区域）。再启动一次只会把那个窗口唤回来，不会开出第二个；到通知区域或任务栏里找它。
  • 源码方式启动失败时，先确认 Python 版本不低于 3.13，依赖已经安装完整，再重新运行一次启动脚本。
  • 命令行里留意启动过程的报错信息，多数问题在最后几行就能看出原因。
  • 界面能打开、但消息发出去没有回复，多半是模型密钥或网络问题。去 设置 → API 测试，用一条最短请求验证链路是否可用。

仍然不通时，对照常见问题排查。
